# Projetos salvos

Esta pasta é a fonte oficial do catálogo de projetos.

- `*.json`: projetos ativos;
- `previews/`: snapshots dos cards;
- `archive/*.json`: projetos arquivados.

Não há espelhamento do catálogo em localStorage/IndexedDB. O armazenamento do navegador é reservado aos rascunhos automáticos dos editores.
